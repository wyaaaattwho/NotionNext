# Analog fonts

Self-hosted Latin fonts obtained from Google Fonts. Files use `font-display: swap`.

- IBM Plex Sans, variable 400–700: SIL Open Font License, `ibm-plex-sans-OFL.txt`.
- Barlow Condensed, 700: SIL Open Font License, `barlow-condensed-OFL.txt`.
- Permanent Marker, 400: Apache License 2.0, `permanent-marker-LICENSE.txt`.

Chinese text uses the device's sans-serif fonts. Code and equations retain their specialized fonts.

Sources: https://github.com/google/fonts/tree/main/ofl/ibmplexsans, https://github.com/google/fonts/tree/main/ofl/barlowcondensed, https://github.com/google/fonts/tree/main/apache/permanentmarker.
